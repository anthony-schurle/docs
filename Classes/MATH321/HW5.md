**Problem 1**
Let $(X,d_X)$ and $(Y,d_Y)$ be two metric spaces and $W\subset X\times Y$. For $x\in X$ we define $W_x=\{y\in Y:(x,y)\in W\}\subset Y$. Show that if $W$ is closed then $W_x$ is closed. Similarly, show that if $W$ is open $W_x$ is open. Lastly, if $W$ is sequentially compact, show that $W_x$ is sequentially compact. In all these statements, the metric on $X\times Y$ is $d_{\mathrm{prod}}$.
**Solution**
Suppose $W$ is closed. Let $y\in Y$ be a limit point of $W_x$ and, for the sake of contradiction, suppose $y\notin W_x$. Then $(x,y)\notin W$. Since $W$ is closed, there is some $\epsilon>0$ such that $N_\epsilon((x,y))\cap W=\emptyset$. We show that $N_\epsilon(y)\cap W_x=\emptyset$. Take $\lambda_Y\in W_x$. By construction, $(x,\lambda_Y)\in W$, so $(x,\lambda_Y)\notin N_\epsilon((x,y))$. Thus $d_X(x,x)+d_Y(y,\lambda_Y)=d_Y(y,\lambda_Y)\ge\epsilon$, and hence $\lambda_Y\notin N_\epsilon(y)$. Therefore $N_\epsilon(y)\cap W_x=\emptyset$, contradicting that $y$ is a limit point of $W_x$. Thus $y\in W_x$, so $W_x$ is closed.

Suppose $W$ is open. Take $y\in W_x$, so $(x,y)\in W$. Since $W$ is open, we have $N_\epsilon((x,y))\subseteq W$ for some $\epsilon>0$. We show $N_\epsilon(y)\subseteq W_x$. Take any $p\in N_\epsilon(y)$. Then $d_Y(y,p)<\epsilon$, and hence $d_X(x,x)+d_Y(y,p)=d_Y(y,p)<\epsilon$. Thus $(x,p)\in W$, so $p\in W_x$. Therefore $N_\epsilon(y)\subseteq W_x$, and $W_x$ is open.

Suppose $W$ is sequentially compact. Let $y_1,y_2,\ldots$ be a sequence in $W_x$. Then $(x,y_1),(x,y_2),\ldots$ is a sequence in $W$. Since $W$ is sequentially compact, there is a subsequence $(x,y_{n_1}),(x,y_{n_2}),\ldots$ converging to some $(a,b)\in W$. Since $d_X(x,a)\le d_{\mathrm{prod}}((x,y_{n_i}),(a,b))$ and the right hand side converges to $0$, we have $d_X(x,a)=0$, so $a=x$. Hence $(x,b)\in W$, meaning $b\in W_x$. Also $d_Y(y_{n_i},b)\le d_{\mathrm{prod}}((x,y_{n_i}),(x,b))\to0$, so $y_{n_i}\to b$. Thus every sequence in $W_x$ has a convergent subsequence whose limit is in $W_x$, so $W_x$ is sequentially compact. $\proofend$

**Problem 2:**
Let $(X,d)$ be a metric space and $\mathcal K$ is a collection of covering compact subsets of $X$. Show that if $\bigcap_{K\in\mathcal K}K=\emptyset$ then there is a finite subset of $\mathcal K$, $\{K_1,\ldots,K_n\}$, so that $\bigcap_{i=1}^nK_i=\emptyset$.
**Solution**
Define $P_K=K^c$ for $K\in\mathcal K$. Since each $K$ is compact, it is closed, so each $P_K$ is open. If $\mathcal K$ is finite then this is immediate, so suppose not. Pick $L\in\mathcal K$. For every $x\in X$, since $x\notin\bigcap_{K\in\mathcal K}K$, there is some $T\in\mathcal K$ such that $x\notin T$, and hence $x\in P_T$. Therefore $X=\bigcup_{K\in\mathcal K}P_K$, so in particular $L\subseteq\bigcup_{K\in\mathcal K}P_K$. Since $L$ is covering compact, there are $K_1,\ldots,K_n\in\mathcal K$ such that $L\subseteq\bigcup_{i=1}^nP_{K_i}$. Thus every $l\in L$ belongs to $P_{K_i}$ for some $i$, meaning $l\notin K_i$. Therefore $L\cap K_1\cap\cdots\cap K_n=\emptyset$. Since $L,K_1,\ldots,K_n\in\mathcal K$, these form a finite subcollection of $\mathcal K$ with empty intersection. $\proofend$

**Problem 3**
Let $(X,d)$ be a metric space, $p\in X$ and $K$ be a sequentially compact subset of $X$. Show that there is $x\in K$ so that $d(y,p)\ge d(x,p)$ for all $y\in K$.
**Solution**
Assuming $K \ne \emptyset$. Let $A=\{d(y,p):y\in K\}\subseteq\mathbb R$. Since $d(y,p)\ge0$ for every $y\in K$, $A$ is bounded below, so let $\alpha=\inf A$. For every $n\in\mathbb N$, $\alpha+\frac1n$ is not a lower bound of $A$, so there exists $x_n\in K$ such that $\alpha\le d(x_n,p)<\alpha+\frac1n$. Since $K$ is sequentially compact, there is a subsequence $x_{n_1},x_{n_2},\ldots$ converging to some $x\in K$. We show that $d(x,p)=\alpha$. Let $\epsilon>0$. Choose $i$ large enough that $d(x_{n_i},x)<\frac\epsilon2$ and $\frac1{n_i}<\frac\epsilon2$. By the triangle inequality, $d(x,p)\le d(x,x_{n_i})+d(x_{n_i},p)<\frac\epsilon2+\alpha+\frac1{n_i}<\alpha+\epsilon$. Since $x\in K$ and $\alpha$ is a lower bound of $A$, we also have $\alpha\le d(x,p)$. Thus $0\le d(x,p)-\alpha<\epsilon$ for every $\epsilon>0$, so $d(x,p)=\alpha$. Finally, for every $y\in K$, $d(y,p)\in A$, so $d(y,p)\ge\alpha=d(x,p)$. $\proofend$
