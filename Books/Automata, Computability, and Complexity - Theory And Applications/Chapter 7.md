## 7.1 Definition Of A Regular Grammar

---

### Definitions

- **Regular Grammar**: A regular grammar is $G = (V, \Sigma, R, S)$ where:
	- $V$ is the rule alphabet containing nonterminals (symbols of the grammars but not of strings in the language) and terminals (symbols that appear in the strings of the language generated by $G$).
	- $\Sigma$ is the set of terminals.
	- $R$ is a finite set of rules with the form $X \to Y$ where $X \subseteq V \backslash \Sigma$ and $Y \subseteq (\{\epsilon\} \cup \Sigma \cup \{aA | a \in \Sigma \text{ and } A \in V \backslash \Sigma\})$.
	- $S$ is a start nonterminal symbol.

## 7.2 Regular Grammars And Regular Languages

---

### Algorithms

**Regular Grammar To FSM**
Constructs a FSM from a given regular grammar.
	`grammartofsm(G: regular grammar) =`
	1. Create in $M$ a separate state for each nonterminal in $V$.
	2. Make the state corresponding to $S$ the start state.
	3. If there any rules in $R$ of the form $X \to w$ for $w \in \Sigma$, the create an additional state $\#$.
	4. For each rule of the form $X \to wY$, add a transition from $X$ to $Y$ labeled $w$.
	5. For each rule of the form $X \to w$, add a transition from $X$ to $\#$ labeled $w$.
	6. For each rule of the form $X \to \epsilon$, mark state $X$ as accepting.
	7. Mark state $\#$ as accepting.
	8. If $M$ is incomplete add a state $D$. For every $(q, i)$ without a defined transition, create a transition from $q$ to $D$ labeled $i$. For every $i \in \Sigma$, create a transition from $D$ to $D$ labeled $i$.

### Results & Proofs

**Theorem: Regular Grammars Define Regular Languages**
The class of languages that can be defined with regular grammars is exactly the regular languages.
