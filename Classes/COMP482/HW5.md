Show a context-free grammar for each of the following languages $L$:
a) $\mathrm{BalDelim}$, the language of strings of delimiters $(,),[,],\{,\}$ that are properly balanced.  
d) $\{w\in\{a,b\}^*\mid \#_a(w)=2\#_b(w)\}$.  
e) $L=\{w\in\{a,b\}^*\mid w=w^R\}$.  
f) $\{a^ib^jc^k\mid i,j,k\ge0\land(i\ne j\lor j\ne k)\}$.
**Solution**
a) Let $\Sigma=\{\texttt{(},\texttt{)},\texttt{[},\texttt{]},\texttt{\{},\texttt{\}}\}$. Then $G=(\{S\}\cup\Sigma,\Sigma,R,S)$, where $R=\{(S,SS),(S,\epsilon),(S,(S)),(S,[S]),(S,\{S\})\}$.

d) $G=(\{S,a,b\},\{a,b\},R,S)$, where $R=\{(S,\epsilon),(S,aSaSbS),(S,aSbSaS),(S,bSaSaS)\}$. 

e) $G=(\{S,a,b\},\{a,b\},R,S)$, where $R=\{(S,\epsilon),(S,a),(S,b),(S,aSa),(S,bSb)\}$.

f) Let $G=(\{S,T,U,A,B,C,a,b,c\},\{a,b,c\},R,S)$, where
$$
\begin{aligned}
R=\{&
(S,TC),(S,AU),\\
&(T,aTb),(T,aA),(T,bB),\\
&(U,bUc),(U,bB),(U,cC),\\
&(A,aA),(A,\epsilon),\\
&(B,bB),(B,\epsilon),\\
&(C,cC),(C,\epsilon)\}.
\end{aligned}
$$

**Problem 12(a)**
Prove that the grammar shown in Example 11.3 is correct for the language $\mathrm{PalEven}=\{ww^R\mid w\in\{a,b\}^*\}$. The grammar is $G=(\{S,a,b\},\{a,b\},\{(S,\epsilon),(S,aSa),(S,bSb)\},S)$.
**Solution**
a) We prove both inclusions. Take $s\in L(G)$, with derivation $s_0=S\Rightarrow_G s_1\Rightarrow_G\cdots\Rightarrow_G s_n=s$. We claim that every $s_k$ satisfies the invariant $I(s_k):\quad \exists u\in\{a,b\}^*\ \exists p\in\{S,\epsilon\}\quad s_k=upu^R$. Initially, $s_0=\epsilon S\epsilon^R$, so $I(s_0)$ holds. Suppose that $I(s_k)$ holds and that another derivation step is possible. Then $s_k=uSu^R$, since $u$ contains only terminals. If the next rule is $S\to aSa$, then $s_{k+1}=uaSau^R=(ua)S(ua)^R$. If it is $S\to bSb$, then $s_{k+1}=ubSbu^R=(ub)S(ub)^R$. If it is $S\to\epsilon$, then $s_{k+1}=uu^R$. Hence the invariant is preserved. Since $s_n=s$ contains only terminals, $s=uu^R$ for some $u\in\{a,b\}^*$. Thus $L(G)\subseteq\mathrm{PalEven}$.

For the reverse inclusion, we induct on $|w|$. If $|w|=0$, then $ww^R=\epsilon$, which is generated by $S\to\epsilon$. Suppose that $tt^R\in L(G)$ where $|t|=k$, and take $w$ with $|w|=k+1$. Either $w=at$ or $w=bt$. If $w=at$, then $ww^R=att^Ra$. By the inductive hypothesis, $S\Rightarrow_G aSa\Rightarrow_G^* att^Ra=ww^R$. If $w=bt$, then $ww^R=btt^Rb$, and similarly $S\Rightarrow_G bSb\Rightarrow_G^* btt^Rb=ww^R$. Thus $\mathrm{PalEven}\subseteq L(G)$. It follows that $L(G)=\mathrm{PalEven}$. $\proofend$

**Problem 13(a, d)**
For each of the following grammars $G$, show that $G$ is ambiguous. Then find an equivalent grammar that is not ambiguous.
a) $G=(\{S,A,B,T,a,c\},\{a,c\},R,S)$, where $R=\{S\to AB,S\to BA,A\to aA,A\to ac,B\to Tc,T\to aT,T\to a\}$.  
d) $G=(\{S,a,b\},\{a,b\},R,S)$, where $R=\{S\to aSb,S\to bSa,S\to SS,S\to\epsilon\}$.
**Solution**
a) The string $acac$ has the following two distinct leftmost derivations:
$$
\begin{aligned}
S&\Rightarrow AB\Rightarrow acB\Rightarrow acTc\Rightarrow acac,\\
S&\Rightarrow BA\Rightarrow TcA\Rightarrow acA\Rightarrow acac.
\end{aligned}
$$
Hence $G$ is ambiguous. Both $A$ and $B$ generate exactly $\{a^nc:n\ge1\}$. Thus $L(G)=\{a^ica^jc:i,j\ge1\}$. An equivalent grammar is $G'=(\{S,A,a,c\},\{a,c\},R',S)$, where $R'=\{(S,AA),(A,aA),(A,ac)\}$. For any string $a^ica^jc$, the first $c$ uniquely determines the boundary between the two $A$-substrings. The first $A$ must use $A\to aA$ exactly $i-1$ times and then $A\to ac$; the second must use it exactly $j-1$ times and then $A\to ac$. Thus every generated string has exactly one leftmost derivation, and $G'$ is unambiguous. $\proofend$

d) The string $ab$ has two distinct leftmost derivations:
$$
\begin{aligned} S&\Rightarrow aSb\Rightarrow ab,\\ S&\Rightarrow SS\Rightarrow aSbS\Rightarrow abS\Rightarrow ab. \end{aligned}
$$
Hence $G$ is ambiguous. An equivalent grammar is $G'=(\{S,A,B,a,b\},\{a,b\},R',S)$, where
$$
\begin{aligned}
R'=\{&
(S,\epsilon),(S,aAbS),(S,bBaS),\\
&(A,\epsilon),(A,aAbA),\\
&(B,\epsilon),(B,bBaB)\}.
\end{aligned}
$$
Here $A$ generates precisely the equal-count strings whose every prefix has at least as many $a$'s as $b$'s, and $B$ generates the analogous strings with $a$ and $b$ interchanged. To see equivalence and uniqueness, take a nonempty equal-count string $w$. If $w$ begins with $a$, let $axb$ be its shortest nonempty prefix having equal counts. Then $w=axby$, where $x$ belongs to the language of $A$ and $y$ again has equal counts. This forces $S\to aAbS$ and uniquely determines its two substrings. If $w$ begins with $b$, the symmetric argument forces $S\to bBaS$. For $A$, the same first-return decomposition uniquely determines the two $A$-substrings in $A\to aAbA$; the symmetric statement holds for $B$. Induction on string length therefore shows that every equal-count string is generated and has exactly one parse tree. Conversely, all the productions preserve equal counts. Thus $G'$ is equivalent to $G$ and unambiguous. $\proofend$

**Problem 3**
Let $L=\{ba^{m_1}ba^{m_2}\cdots ba^{m_n}\mid n\ge2,\ m_1,\ldots,m_n\ge0,\text{ and }m_i\ne m_j\text{ for at least one pair }i,j\}$.
a) Show a PDA that accepts $L$.  
b) Show a context-free grammar that generates $L$.  
c) Prove that $L$ is not regular.
**Solution**
a) Let $M=(\{s,p,q,r,u,v,f\},\{a,b\},\{X,Z\},\Delta,s,\{f\})$, where $\Delta$ is given by:

| State | Input | Pop | Next state | Push |
|---|---|---|---|---|
| $s$ | $b$ | $\epsilon$ | $p$ | $Z$ |
| $s$ | $b$ | $\epsilon$ | $q$ | $Z$ |
| $p$ | $a$ | $\epsilon$ | $p$ | $\epsilon$ |
| $p$ | $b$ | $\epsilon$ | $p$ | $\epsilon$ |
| $p$ | $b$ | $\epsilon$ | $q$ | $\epsilon$ |
| $q$ | $a$ | $\epsilon$ | $q$ | $X$ |
| $q$ | $b$ | $\epsilon$ | $r$ | $\epsilon$ |
| $r$ | $a$ | $X$ | $r$ | $\epsilon$ |
| $r$ | $a$ | $Z$ | $u$ | $Z$ |
| $r$ | $b$ | $X$ | $u$ | $X$ |
| $r$ | $\epsilon$ | $X$ | $v$ | $\epsilon$ |
| $u$ | $a$ | $\epsilon$ | $u$ | $\epsilon$ |
| $u$ | $b$ | $\epsilon$ | $u$ | $\epsilon$ |
| $u$ | $\epsilon$ | $X$ | $u$ | $\epsilon$ |
| $u$ | $\epsilon$ | $Z$ | $f$ | $\epsilon$ |
| $v$ | $\epsilon$ | $X$ | $v$ | $\epsilon$ |
| $v$ | $\epsilon$ | $Z$ | $f$ | $\epsilon$ |

b) Let $G=(\{S,P,T,A,a,b\},\{a,b\},R,S)$, where
$$
\begin{aligned}
R=\{&
(S,PbTP),\\
&(P,bAP),(P,\epsilon),\\
&(A,aA),(A,\epsilon),\\
&(T,aTa),(T,aAb),(T,baA)\}.
\end{aligned}
$$

c) Suppose, for contradiction, that $L$ is regular. Then some DFSM $D$ with $N$ states accepts $L$. Consider the $N+1$ prefixes $x_k=ba^k$ for $0\le k\le N$. By the pigeonhole principle, there exist $i<j$ such that $D$ reaches the same state after reading $x_i$ and $x_j$. Append the same suffix $z=ba^i$ to each prefix. Then $x_i z=ba^iba^i\notin L$, while $x_j z=ba^jba^i\in L$. But a deterministic machine in the same state must respond identically to the same remaining input $z$. This is a contradiction. Thus $L$ is not regular. $\proofend$
