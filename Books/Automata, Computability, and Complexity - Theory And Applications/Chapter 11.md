## 11.1 Introduction To Rewrite Systems And Grammars

---

### Key Concepts

- **Rewrite System (Production System) (Rule-Based System)**: List of rules and algorithm for applying them.
- **Rewrite-System Formalism**: Specification for form of rules and algorithm applied. Typically rules are pairs of strings.
- **Grammar**: Rewrite system used to define a language. Has an alphabet $V$. Has start symbol, usually $S$.
- **Terminal Alphabet**: Denoted $\Sigma$, are the symbols that make up $L(G)$ for grammar $G$.
- **Nonterminal Alphabet**: Working symbols used while a grammar is operating, not contained in $\Sigma$.
- **Grammar Formalism**: Rewrite-system formalism for grammars.
- **Derive**: If `simple-rewrite(R, w)` an return string $s$, then we say $R$ derives $s$ from $w$, denoted $w \implies s$.
- **Generated**: Working string does not contain nonterminal symbols after derivation process.

### Algorithms

**Rewrite Algorithm**
Carries out rewrites with the system $R$.
	`simple-rewrite(R: rewrite system, w: initial string) =`
		1. Set $\text{working-string}$ to $w$.
		2. Until told by $R$ to halt do:
			1. Match the left side of some rule against some part of $\text{working-string}$.
			2. Replace the matched part of $\text{working-string}$ with the right-hand side of the rule that was matched.
		3. Return $\text{working-string}$.

## 11.2 Context-Free Grammars And Languages

---

### Key Concepts

- **Context-Free Grammar Notation**: Various notation for context-free grammars. 
	- $S \to \alpha | \beta | \lambda | ...$ denotes that $(S, \alpha), (S, \beta), (S, \lambda), ... \in R_G$.
	- $\text{<var>} \in V - \Sigma$ denotes a nonterminal whose ontological status does not take that of a character.

### Definitions

- **Context-Free Grammar**: $G = (V, \Sigma, R, S)$ where:
	- $V$ is the rule alphabet.
	- $\Sigma \subseteq V$ are the terminal symbols.
	- $R \subseteq (V - \Sigma) \times V^*$ is a finite set of rules.
	- $S \in V - \Sigma$ is the start symbol.
	- Language generated, $L(G) = \{w \in \Sigma^* | S \Rightarrow_G^* w\}$.
- **Derives-In-One-Step**: $\forall x,y \in V^* (x \Rightarrow_G y \iff (x = \alpha A \beta, y = \alpha \gamma \beta \land \exists (A, \gamma) \in R_G) )$.
- **Derivation**: Sequence $w_0 \Rightarrow_G w_1 \Rightarrow_G ... \Rightarrow_G w_n$.
- **Derives Relation**: Reflexive, transitive closure of $\Rightarrow_G$, denoted $\Rightarrow_G^*$.
- **Context-Free Language**: Language generated by a context-free grammar.
- **Recursive**: $r \in R_G$ is recursive iff $r = (X, w_1Yw_2)$ where $Y \Rightarrow_G^* w_3Xw_4$ for $w_1, w_2, w_3, w_4 \in V^*$. The grammar is called recursive if it contains a recursive rule.
- **Self-Embedding**: $r \in R_G$ is self-embedding iff $r = (X, w_1Yw_2)$ where $Y \Rightarrow_G^* w_3Xw_4$ and $w_1w_3, w_4w_2 \in \Sigma^+$. The grammar is called self-embedding if it contains a self-embedding rule.

## 11.4 Simplifying Context-Free Grammars

---

### Algorithms

**Remove Unproductive Nonterminals**
Removes unproductive nonterminal symbols and rules from a grammar.
	`removeunproductive(G: CFG) =`
		1. $G' = G$.
		2. Mark every nonterminal symbol in $G'$ as unproductive.
		3. Mark every terminal symbol in $G'$ as productive.
		4. Until one entire pass has been made without any new symbol being marked do:
			1. For each rule $(X, \alpha) \in R_G$ do:
				1. If every symbol in $\alpha$ has been marked as productive and $X$ has not yet been marked as productive, then mark $X$ as productive.
		5. Remove from $V_{G'}$ every unproductive symbol.
		6. Remove from $R_{G'}$ every rule with an unproductive symbol. 
		7. Return $G'$.

**Remove Unreachable Nonterminals**
Removes unreachable nonterminal symbols and rules from a grammar.
	`removeunreachable(G: CFG) =`
		1. $G' = G$.
		2. Mark $S$ as reachable.
		3. Mark every other nonterminal symbol as unreachable.
		4. Until one entire pass has been made without any new symbol being marked do:
			1. For each rule $(X, \alpha A \beta) \in R_G$ do:
				1. If $X$ has been marked as reachable and $A$ has not, then mark $A$ as reachable.
		5. Remove from $V_{G'}$ every unreachable symbol.
		6. Remove from $R_{G'}$ every rule with an unreachable symbol. 
		7. Return $G'$.

## 11.6 Derivations And Parse Trees

---

### Definitions

- **Parse Tree**: Rooted, ordered tree derived by grammar $G = (V, \Sigma, R, S)$ in which:
	- Every leaf node is labeled with an element of $\Sigma \cup \{\epsilon\}$.
	- The root node is labeled $S$.
	- Every other node is labeled with some element of $V - \Sigma$.
	- If $m$ is a nonleaf node labeled $X$ with children $x_1, x_2, x_3, ..., x_n$, then $R$ contains the rule $(X, x_1 x_2 ... x_n)$.
- **Branching Factor**: Longest length (number of symbols) right-hand side of a rule in a grammar.
- **Weak Generative Capacity**: $L(G)$ for grammar $G$.
- **Strong Generative Capacity**: Set of parse trees that $G$ generates.
- **Left-Most Derivation**: Leftmost nonterminal chosen first in expansion.
- **Right-Most Derivation**: Rightmost nonterminal chosen first in expansion.

## 11.7 Ambiguity

---

### Key Concepts

- **Removing Symmetric Recursive Rules**: Rules of the form $S \to SS...$ can cause ambiguity. We can force $S$ to do branching, and then set some $S_1$ to do the other rules of $S$.
- **Dangling Else Problem**: Example of ambiguous attachment. Consider $<stmt> \to \text{if} <cond> \text{then} <stmt>$ and $<stmt> \to \text{if} <cond> \text{then} <stmt> \text{else} <stmt>$. Then $\text{if} \text{ cond}_1 \text{ then} \text{ if} \text{ cond}_2 \text{ then} \text{ st}_1 \text{ else} \text{ st}_2$ has two parse trees.
- **Proving Unambiguity**: $G$ is unambiguous iff every string derivable in the grammar has a single leftmost derivation.

### Definitions

- **Ambiguous**: Grammar $G$ is ambiguous iff $\exists s \in L(G)$ for which $G$ produces more than one parse tree.
- **Inherently Ambiguous**: Context-free languages for which no unambiguous grammar exists.
- **$\epsilon$-Rule** Rule whose right-hand side is $\epsilon$.

### Algorithms

**Remove $\epsilon$-Rule Ambiguity**
Removes $\epsilon$-Rules from a grammar $G = (V, \Sigma, R, S)$ by constructing $G'$ with $L(G') = L(G) - \{\epsilon\}$.
	`removeEps(G : CFG) =`
		1. Let $G' = G$.
		2. Find the set $N$ of nullable variables in $G'$. A variable $X$ is nullable iff either there is a rule $(X, \epsilon)$ or there is a rule $(X, PQR...)$ such that $P, Q, R, ...$ are nullable. So compute $N$ as follows:
			1. Set $N$ to the set of variables with rules $(X, \epsilon)$.
			2. Until an entire pass has been made without adding anything to $N$ do:
				1. Evaluate all other variables with respect to $(X, PQR...)$. Insert variables satisfying the nullable property.
		3. Define a rule to be modifiable iff $(P, \alpha Q \beta)$ for $Q \in N$ and $\alpha, \beta \in V^*$. Repeat until $G'$ contains no modifiable rules that have not been processed:
			1. Given $P \to \alpha Q \beta$ with $Q \in N$, add the rule $P \to \alpha \beta$ if not present, $\alpha \beta \ne \epsilon$, and $\alpha \beta \ne P$.
		4. Delete from $G'$ all $\epsilon$-rules.
		5. Return $G'$.

**Remove $\epsilon$-Rule Ambiguity And Preserve $\epsilon$**
Removes $\epsilon$-Rules from a grammar $G = (V, \Sigma, R, S)$ by constructing $G'$ with $L(G') = L(G)$.
	`atmostoneEps(G : CFG) =`
		1. $G'' =$ `removeEps(G)`.
		2. If $S_G$ is nullable then:
			1. Create in $G''$ a new start symbol $S^*$.
			2. Add to $R_{G''}$ the two rules $(S^*, \epsilon)$ and $(S^*, S_G)$.
		3. Return $G''$.

## 11.8 Normal Forms

---

### Key Concepts

- **Normal Form**: Let $C$ be a set of data objects (like grammars). Set $F$ is a normal form for $C$ iff:
	- For every $c \in C$ (except possibly finite elements), $\exists f \in F$ such that $f \equiv c$ with respect to some set of tasks.
	- $F$ is simpler (some tasks easier to perform) than the original form in which the elements of $C$ are written.

### Definitions

- **Chomsky Normal Form**: For grammar $G = (V, \Sigma, R, S)$ we require for all rules:
	- $(X, a)$ where $a \in \Sigma$ or,
	- $(X, BC)$ for $B, C \in V - \Sigma$.
- **Greibach Normal Form**: For grammar $G = (V, \Sigma, R, S)$ we require for all rules:
	- $(X, \alpha \beta)$ where $\alpha \in \Sigma$ and $\beta \in (V - \Sigma)^*$.
- **Unit Production**: Rule of the form $(A, B)$ where $A, B \in (V - \Sigma)$.

### Algorithms

**Remove Units**
Removes unit productions from a grammar.
	`removeUnits(G: CFG) =`
		1. Let $G' = G$.
		2. Until no productions remain in $G'$ do:
			1. Choose some unit production $(X, Y)$.
			2. Remove it from $G'$.
			3. Considering rules remaining in $G'$, for every $(Y, \beta)$ where $\beta \in V^*$ do:
				1. Add to $G'$ the rule $(X, \beta)$ unless that is a rule that has already been removed once.
		3. Return $G'$.

**Remove Mixed**
Removes rules with right hand sides of length 2 or greater containing symbols from both $\Sigma$ and $V - \Sigma$.
	`removedMixed(G: CFG) =`
	1. Let $G' = G$.
	2. Create a new nonterminal $T_a$ for each terminal $a \in \Sigma$.
	3. Modify each rules in $G'$ whose right hand side has length greater than 1 and that contains a terminal symbol by substituting $T_a$ for each occurrence of the terminal $a$.
	4. Add to $G'$, for each $T_a$, the rule $T_a \to a$.
	5. Return $G'$.

**Remove Long**
Removes rules with right hand sides of length greater than 2 with only nonterminal symbols.
	`removeLong(G: CFG) =`
		1. Let $G' = G$.
		2. For each rule $r^k$ in $G'$ of the form $(A, N_1N_2...N_n)$ with $n > 2$, create nonterminals $M^k_2, M^k_3, ..., M^k_{n-1}$.
		3. In $G'$, replace $r^k$ with $(A, N_1M^k_2)$.
		4. To $G'$, add the rules $(M^k_2, N_2M^k_3), (M^k_3, N_3M^k_4), ..., (M^k_{n-1}, N_{n-1}N)$.
		5. Return $G'$.

**Chomsky Conversion**
Converts a grammar $G = (V, \Sigma, R, S)$ of length $n$ into a new grammar $G_C$ such that $G_C$ is in Chomsky normal form and $L(G_C) = L(G) - \{\epsilon\}$.
_Time Complexity: $\mathcal{O}(n)$_  
	`converttoChomsky(G : CFG) =`
		1. $G_C =$ `removeLong(`$G_C$`)`.
		2. $G_C =$ `removeEps(G)`.
		3. $G_C =$ `removeUnits(`$G_C$`)`.
		4. $G_C =$ `removeMixed(`$G_C$`)`.
		5. Return $G_C$.

### Results & Proofs

**Theorem: Chomsky Normal Form**
Given a context-free grammar $G$, $\exists$ an equivalent Chomsky normal form grammar $G_C$ such that $L(G_C) = L(G) - \{\epsilon\}$.

**Theorem: Greibach Normal form**
Given a context-free grammar $G$, $\exists$ an equivalent Greibach normal form grammar $G_G$ such that $L(G_G) = L(G) - \{\epsilon\}$.

**Theorem: Rule Substitution**
Let $G = (V, \Sigma, R, S)$ be a context-free grammar with $r = (X, \alpha Y \beta) \in R$  where $\alpha, \beta \in V^*$ and $Y \in (V - \Sigma)$. Let $Y \to \gamma_1 | \gamma_2 | ... | \gamma_n$ be all of $G$'s rules whose left hand side is $Y$. And let $G'$ be the result of removing $r$ from $R$ and replacing it with the rules $(X, \alpha \gamma_1 \beta), (X, \alpha \gamma_2 \beta), ..., (X, \alpha \gamma_n \beta)$. Then $L(G') = L(G)$.
