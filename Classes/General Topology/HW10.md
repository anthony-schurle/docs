1) Theorem. Let $f : X \to Y$; let Y be compact Hausdorff. Then f is continuous iff the graph of f, $G_f = \{x \times f(x) | x \in X\}$, is closed in $X \times Y$. Hint: If $G_f$ is closed and V is a neighborhood of $f(x_0)$, then the intersection of $G_f$ and $X \times (Y - V)$ is closed. Apply excercise 7 - "Show that if Y is compact, then the projection $\pi_1 : X \times Y \to X$ is a closed map".

First suppose $f$ is continuous. Let $(x_0,y_0)\notin G_f$. Then $y_0\neq f(x_0)$. Since $Y$ is Hausdorff, there exist disjoint open sets $U,V\subset Y$ such that $f(x_0)\in U$ and $y_0\in V$. Since $f$ is continuous, $f^{-1}(U)$ is open in $X$, so $f^{-1}(U)\times V$ is an open neighborhood of $(x_0,y_0)$ in $X\times Y$. This neighborhood is disjoint from $G_f$, because if $(x,f(x))\in f^{-1}(U)\times V$, then $f(x)\in U\cap V$, a contradiction. Hence every point of $(X\times Y)-G_f$ has an open neighborhood disjoint from $G_f$, so $(X\times Y)-G_f$ is open and $G_f$ is closed. Conversely, suppose $G_f$ is closed in $X\times Y$. Let $V$ be open in $Y$. Then $Y-V$ is closed, so $X\times (Y-V)$ is closed ($\pi_2^{-1}(Y - V)$ for continuous $\pi_2$) in $X\times Y$, and hence $C=G_f\cap (X\times (Y-V))$ is closed in $X\times Y$ by Theorem 17.1. Since $Y$ is compact, $\pi_1:X\times Y\to X$ is a closed map by Exercise 7. Therefore $\pi_1(C)$ is closed in $X$. But $\pi_1(C)=\{x\in X:f(x)\in Y-V\}=X-f^{-1}(V)$, so $f^{-1}(V)$ is open in $X$. Since this holds for every open set $V\subset Y$, $f$ is continuous. Thus $f$ is continuous if and only if $G_f$ is closed in $X\times Y$. $\proofend$

2) Let $p : X \to Y$ be a closed continuous surjective map such that $p^{-1}(\{y\})$ is compact, for each $y \in Y$. (Called a perfect map) Show that if Y is compact, then X is compact. Hint: If U is an open set containg $p^{-1}(\{y\})$, there is a neighborhood W of y such that $p^{-1}(W)$ is contained in U.

Let $\mathcal U$ be an open cover of $X$. For each $y\in Y$, the compact set $p^{-1}(\{y\})$ is covered by $\mathcal U$, so there are finitely many sets $U_{y,1},\dots,U_{y,n_y}\in\mathcal U$ such that $p^{-1}(\{y\})\subset U_{y,1}\cup\cdots\cup U_{y,n_y}$. Set $U_y=U_{y,1}\cup\cdots\cup U_{y,n_y}$. Then $U_y$ is open and contains $p^{-1}(\{y\})$. We claim that there is an open neighborhood $W_y$ of $y$ such that $p^{-1}(W_y)\subset U_y$. To see this, let $C=X-U_y$. Then $C$ is closed in $X$, so $p(C)$ is closed in $Y$ because $p$ is a closed map. Also $y\notin p(C)$, since otherwise there would be some $x\in C$ with $p(x)=y$, meaning $x\in p^{-1}(\{y\})\subset U_y$, contradicting $x\in C=X-U_y$. Hence $W_y=Y-p(C)$ is an open neighborhood of $y$. If $x\in p^{-1}(W_y)$, then $p(x)\notin p(C)$, so $x\notin C$, and therefore $x\in U_y$. Thus $p^{-1}(W_y)\subset U_y$. Now $\{W_y:y\in Y\}$ is an open cover of $Y$, so by compactness of $Y$ there are $y_1,\dots,y_m\in Y$ such that $Y=W_{y_1}\cup\cdots\cup W_{y_m}$. Since $p$ is surjective, $X=p^{-1}(Y)=p^{-1}(W_{y_1})\cup\cdots\cup p^{-1}(W_{y_m})$. For each $i$, we have $p^{-1}(W_{y_i})\subset U_{y_i}$, and each $U_{y_i}$ is a finite union of members of $\mathcal U$. Therefore finitely many members of $\mathcal U$ cover $X$, so $X$ is compact. $\proofend$

3) Show that connected metric space having more than one point is uncountable.

Let $(X,d)$ be a connected metric space with more than one point. Choose distinct points $a,b\in X$, and define $g:X\to\mathbb R$ by $g(x)=d(a,x)$. This map is continuous because $|g(x)-g(y)|=|d(a,x)-d(a,y)|\le d(x,y)$. Since $X$ is connected, $g(X)$ is connected in $\mathbb R$ since the continuous image of a connected space is connected. Also $g(a)=0$ and $g(b)=d(a,b)>0$. Because connected subspaces of $\mathbb R$ are intervals, $g(X)$ contains every real number between $0$ and $d(a,b)$; that is, $[0,d(a,b)]\subset g(X)$. But $[0,d(a,b)]$ is uncountable, so $g(X)$ is uncountable. Since the image of a countable set under any function is countable, $X$ itself cannot be countable. $\proofend$

4) Let $X$ be limit point compact. a) If $f:X\to Y$ is continuous, does it follow that $f(X)$ is limit point compact? b) If $A$ is a closed subset of $X$, does it follow that $A$ is limit point compact?

a) No. Let $X=\mathbb N\times\{0,1\}$, and give $X$ the topology whose open sets are arbitrary unions of the two-point sets $F_n=\{n\}\times\{0,1\}$. Thus each $F_n$ has the indiscrete topology, and $X$ is the topological sum of these two-point indiscrete spaces. Every infinite subset $B\subset X$ has a limit point: choose any $(n,i)\in B$; then the other point $(n,1-i)$ is a limit point of $B$, because every neighborhood of $(n,1-i)$ contains the whole fiber $F_n$, hence contains $(n,i)\in B$. Therefore $X$ is limit point compact. Now define $f:X\to\mathbb N$ by $f(n,i)=n$, where $\mathbb N$ has the discrete topology. For every subset $S\subset\mathbb N$, $f^{-1}(S)=\bigcup_{n\in S}F_n$, which is open in $X$, so $f$ is continuous. But $f(X)=\mathbb N$ is an infinite discrete space, and an infinite discrete space is not limit point compact, since no point is a limit point of $\mathbb N$. $\proofend$

b) Yes. Let $A$ be a closed subset of $X$, and let $B$ be an infinite subset of $A$. Since $X$ is limit point compact, $B$ has a limit point $x\in X$. Because $B\subset A$ and $A$ is closed, every limit point of $B$ lies in $A$, so $x\in A$. Now let $U$ be a neighborhood of $x$ in the subspace $A$. Then $U=A\cap V$ for some open set $V$ of $X$ containing $x$. Since $x$ is a limit point of $B$ in $X$, the set $V$ contains some point $b\in B$ with $b\neq x$. Since $B\subset A$, we have $b\in A\cap V=U$. Thus every neighborhood of $x$ in $A$ meets $B$ in a point other than $x$, so $x$ is a limit point of $B$ in $A$. $\proofend$

5) A space $X$ is said to be countably compact if every countable open covering of $X$ contains a finite subcollection that covers $X$. Show that for a $T_1$ space $X$, countable compactness is equivalent to limit point compactness. Hint: If no finite subcollection of $U_n$ covers $X$, choose $x_n\notin U_1\cup\cdots\cup U_n$, for each $n$.

First suppose $X$ is countably compact. Let $A$ be an infinite subset of $X$, and choose a countably infinite subset $B=\{b_1,b_2,\dots\}$ of $A$. Suppose, for contradiction, that $B$ has no limit point. A set is closed iff it contains all its limit points, so each tail $B_n=\{b_n,b_{n+1},\dots\}$ is closed. Hence $U_n=X-B_n$ is open. The collection $\{U_n:n\in\mathbb N\}$ is a countable open cover of $X$: every point outside $B$ lies in $U_1$, and $b_k\in U_{k+1}$. But no finite subcollection covers $X$, because $U_1\subset U_2\subset\cdots$, and $U_N$ misses the infinite tail $B_N$. This contradicts countable compactness. Therefore $B$, and hence $A$, has a limit point, so $X$ is limit point compact. Conversely, suppose $X$ is limit point compact. Let $\{U_n:n\in\mathbb N\}$ be a countable open cover of $X$. Suppose no finite subcollection covers $X$. Then for each $n$, choose $x_n\notin U_1\cup\cdots\cup U_n$. The set $\{x_n:n\in\mathbb N\}$ is infinite, because each point of $X$ belongs to some $U_N$, and after stage $N$ it can no longer be chosen. Since $X$ is limit point compact, this infinite set has a limit point $x$. Since $\{U_n\}$ covers $X$, there is some $U_N$ with $x\in U_N$. In a $T_1$ space, every neighborhood of a limit point of a set contains infinitely many points of that set, so $U_N$ contains some $x_n$ with $n\ge N$. But by construction, $x_n\notin U_1\cup\cdots\cup U_n$, and since $N\le n$, this implies $x_n\notin U_N$, a contradiction. Hence some finite subcollection of $\{U_n\}$ covers $X$, so $X$ is countably compact. $\proofend$

6) Let $(X,d)$ be a metric space. If $f:X\to X$ satisfies the condition $d(f(x),f(y))=d(x,y)$ for all $x,y\in X$, then $f$ is called an isometry of $X$. Show that if $f$ is an isometry and $X$ is compact, then $f$ is bijective and hence a homeomorphism. Hint: If $a\notin f(X)$, choose $\epsilon$ so that the $\epsilon$-neighborhood of $a$ is disjoint from $f(X)$. Set $x_1=a$, and $x_{n+1}=f(x_n)$ in general. Show that $d(x_n,x_m)\ge\epsilon$ for $n\ne m$.

First, $f$ is injective: if $f(x)=f(y)$, then $d(x,y)=d(f(x),f(y))=0$, so $x=y$. Also $f$ is continuous, because $d(f(x),f(y))=d(x,y)$, so taking $\delta=\epsilon$ proves continuity. We now prove that $f$ is surjective. Suppose not, and choose $a\in X-f(X)$. Since $X$ is compact and $f$ is continuous, $f(X)$ is compact because continuous images of compact spaces are compact. Since $X$ is metric, compact subsets are closed, so $f(X)$ is closed. Therefore there exists $\epsilon>0$ such that $B_d(a,\epsilon)\cap f(X)=\varnothing$. Define $x_1=a$ and $x_{n+1}=f(x_n)$. If $n<m$, then by repeatedly using the isometry condition, $d(x_n,x_m)=d(f^{n-1}(a),f^{m-1}(a))=d(a,f^{m-n}(a))$. Since $m-n\ge1$, the point $f^{m-n}(a)$ lies in $f(X)$, so $d(a,f^{m-n}(a))\ge\epsilon$. Hence $d(x_n,x_m)\ge\epsilon$ whenever $n\ne m$. Thus the infinite set $\{x_n:n\in\mathbb N\}$ has all distinct points separated by distance at least $\epsilon$. But this is impossible in a compact metric space: the open cover of $X$ by all balls of radius $\epsilon/2$ has a finite subcover, and each such ball contains at most one $x_n$, contradicting the infinitude of the sequence. Therefore $f(X)=X$, so $f$ is surjective. Thus $f$ is bijective. Finally, since $f$ is a bijective isometry, its inverse is also an isometry, hence continuous. Therefore $f$ is a homeomorphism. $\proofend$
