**Problem 1(a, b, c, d)**
Show a regular grammar for each of the following languages:
a) $\{w \in \{a, b\}^* | \text{w contains an even number of a’s and an odd number of b’s}\}$.
b) $\{w \in \{a, b\}^* | \text{w does not end in aa}\}$.
c) $\{w \in \{a, b\}^* | \text{w contains the substring abb}\}$.
d) $\{w \in \{a, b\}^* | \text{if w contains the substring aa then |w| is odd}\}$.
**Solution**
a)
Define $G = (\{a, b, S, A, B, C\}, \{a, b\}, R, S)$ where the rule set $R$ is given by $R = \{S \to aA, S \to bB, A \to aS, A \to bC, B \to aC, B \to bS, B \to \epsilon, C \to aB, C \to bA\}$. 

b)
Define $G = (\{a, b, S, A, A'\}, \{a, b\}, R, S)$ where the rule set $R$ is given by $R = \{S \to aA, S \to bS, S \to \epsilon, A \to bS, A \to aA', A \to \epsilon, A' \to aA', A' \to bS\}$.

c)
Define $G = (\{a, b, S, A, B, B'\}, \{a, b\}, R, S)$ where the rule set $R$ is given by $R = \{S \to aA, S \to bS, A \to aA, A \to bB, B \to aA, B \to bB', B' \to aB', B' \to bB', B' \to \epsilon\}$.

d)
Define $G = (\{a, b, S, S', O, E, X, Y\}, \{a, b\}, R, S)$ where the rule set $R$ is given by,
$$
\begin{align}
R = \{& \\
&S \to \epsilon, S \to aO, S \to bS' \\
&S' \to \epsilon, S' \to aE, S' \to bS, \\
&O \to \epsilon, O \to aX, O \to bS, \\
&E \to \epsilon, E \to aY, E \to bS' \\
&X \to aY, X \to bY, \\
&Y \to \epsilon, Y \to aX, Y \to bX \\
&\}
\end{align}
$$

**Problem 1(b, c, d, e, f)**
Define a decision procedure for each of the following questions. Argue that each of your decision procedures gives the correct answer and terminates.
b) Given two DFSMs $M_1$ and $M_2$ is $|L(M_1)| < |L(M_2)|$?
c) Given a regular grammar $G$ and a regular expression $\alpha$, is $L(G) = L(\alpha)$?
d) Given two regular expressions, $\alpha$ and $\beta$, do there exist any even length strings that are in $L(\alpha)$ but not $L(\beta)$?
e) Let $\Sigma = \{a, b\}$ and let $\alpha$ be a regular expression. Does the language generated by $\alpha$ contains all the even length strings in $\Sigma^*$.
f) Given an FSM $M$ and a regular expression $\alpha$, does $M$ accept exactly two more strings than $\alpha$ generates?
**Solution**
Suppose $D$ is a DFSM with $n$ states and $L(D)$ is finite. Every accepted string must have length less than $n$. Otherwise, an accepting computation would repeat a state, creating a nonempty loop that could be repeated arbitrarily often. This would make $L(D)$ infinite. After establishing finiteness, we can therefore use bounded simulation:
```text
countFinite(D: DFSM) =
    n = number of states of D
    count = 0
    for every w over D's alphabet with |w| < n:
        if decideFSM(D, w):
            count = count + 1
    return count
```

This counts every accepted string exactly once, including $\varepsilon$ if accepted. It terminates because it examines finitely many strings.

b)
```text
    if not finiteFSM(M1):
        return False
    if not finiteFSM(M2):
        return True
    return countFinite(M1) < countFinite(M2)
```

If $L(M_1)$ is infinite, the answer is False. Every infinite language over a finite alphabet is countably infinite, so its cardinality cannot be strictly smaller than that of another language over a finite alphabet. If $L(M_1)$ is finite and $L(M_2)$ is infinite, the answer is True. If both languages are finite, comparing their exact counts gives the correct answer. `finiteFSM` terminates, and `countFinite` is called only on DFSMs whose languages have been established to be finite.

c)
1. Use `grammartofsm` to construct an FSM $M_G$ such that $L(M_G)=L(G)$.
2. Use `regextofsm` to construct an FSM $M_\alpha$ such that $L(M_\alpha)=L(\alpha)$.
3. Return `equalFSMs(M_G, M_alpha)`.
The conversions preserve the languages, so $L(G)=L(\alpha)$ if and only if $L(M_G)=L(M_\alpha)$. The chapter’s equivalence procedure decides exactly this question. Both conversions and `equalFSMs` terminate.

d)
Let $\Sigma$ contain all symbols occurring in either expression. Construct a two-state DFSM $E$ accepting $L(E)=\{w\in\Sigma^*:|w|\text{ is even}\}$. Its states represent even and odd length. Every input symbol switches states, and the even state is both the start state and the only accepting state.
1. Convert $\alpha$ and $\beta$ to FSMs $M_\alpha$ and $M_\beta$ by `regextofsm`.
2. Using difference and intersection, construct an FSM $N$ such that $L(N)=(L(M_\alpha)-L(M_\beta))\cap L(E)$.
3. Return `not emptyFSM(N)`.
A string belongs to $L(N)$ exactly when it has even length, belongs to $L(\alpha)$, and does not belong to $L(\beta)$. Therefore, the desired string exists if and only if $L(N)$ is nonempty. The conversions, closure constructions, and emptiness test all terminate.

e)
The language of all even-length strings is $\mathrm{Even}=L(((a\cup b)(a\cup b))^*)$.
1. Construct an FSM $E$ accepting $\mathrm{Even}$ using `regextofsm`.
2. Convert $\alpha$ to an FSM $M_\alpha$ by `regextofsm`.
3. Construct an FSM $N$ accepting $L(N)=L(E)-L(M_\alpha)$.
4. Return `emptyFSM(N)`.
The language $L(N)$ consists exactly of the even-length strings missing from $L(\alpha)$. Thus, $\mathrm{Even}\subseteq L(\alpha)$ if and only if $\mathrm{Even}-L(\alpha)=\varnothing$. The string $\varepsilon$ has even length and is included in this test. All constructions and the emptiness test terminate.

f)
1. Use `regextofsm` to construct an FSM $A$ such that $L(A)=L(\alpha)$.
2. Construct an FSM $B$ accepting $L(A)-L(M)$.
3. If `emptyFSM(B)` is False, return False.
4. Using the difference construction and `ndfsmtodfsm`, construct a DFSM $D$ accepting $L(M)-L(A)$.
5. If `finiteFSM(D)` is False, return False.
6. Return whether `countFinite(D) = 2`.
Here, `countFinite(D)` counts accepted strings by running `decideFSM(D,w)` on every string $w$ with $|w|<n$, where $n$ is the number of states of $D$. This counts the entire language after finiteness has been established. Step 3 checks that every string generated by $\alpha$ is accepted by $M$, since $L(A)-L(M)=\varnothing$ exactly when $L(\alpha)\subseteq L(M)$. The language $L(D)=L(M)-L(\alpha)$ contains precisely the additional strings accepted by $M$. If it is infinite, it cannot contain exactly two strings. Otherwise, the final step counts its strings and returns True exactly when there are two. Thus, the procedure returns True exactly when $M$ accepts everything $\alpha$ generates and exactly two additional strings. The conversions, difference constructions, emptiness test, and finiteness test all terminate. The counting step examines finitely many strings and uses a terminating membership procedure.

**Problem 15(a, b, c, d, e)**
Give examples to show that
a) The intersection of two countably infinite sets can be finite.
b) The intersection of two countably infinite sets can be countably infinite.
c) The intersection of two uncountable sets can be finite.
d) The intersection of two uncountable sets can be countably infinite.
e) The intersection of two uncountable sets can be uncountable.
**Solution**
We assume the natural numbers do not include $0$ throughout.
a)
Denote $Z^- = \{a \in \mathbb{Z} | a < 0\}$ and $Z^+ = \{a \in \mathbb{Z} | a > 0\}$. Clearly, $Z^- \cap Z^+ = \emptyset$ which is finite, else we have $p > 0$ and $p < 0$ which is impossible. All that remains to show is that $Z^-$ and $Z^+$ are countably infinite. Let $f(n) = n$ and $g(n) = -n$. We claim $f$ forms a bijection between the natural numbers to $Z^+$ and $g$ forms a bijection from the natural numbers to $Z^-$. Suppose $f(x) = f(y)$. Then $x=y$ as desired, meaning $f$ is 1-1. Consider any $j \in Z^+$. Then $0 < j$ so $j \in \mathbb{N}$. Notice $f(j) = j$. Hence $f$ is a bijection. Suppose $g(x) = g(y)$. Then $-(x) = -(y)$ and so $x=y$ making $g$ 1-1. Now let $v \in Z^-$. Then $v < 0$ so that $-v > 0$. Hence $-v \in \mathbb{N}$. But then $g(-v) = -(-v) = v$ as wanted. Therefore, $g$ is a bijection. Thus, both $Z^-$ and $Z^+$ are indeed infinitely countable. $\proofend$

b)
The book showed that the set $E$ of even natural numbers is countably infinite. But $E \subseteq \mathbb{N}$ and so $E \cap \mathbb{N} = E$ as desired ($\mathbb{N}$ is obviously countably infinite). $\proofend$

c)
Take $N = \mathcal{P}(Z^-)$ and $M = \mathcal{P}(Z^+)$ which are uncountably infinite since $Z^-$ and $Z^+$ are countably infinite as shown in part a. We claim $N \cap M = \{\emptyset\}$, which is clearly finite by the function $f = \{(1, \emptyset)\}$. Suppose $p \in N \cap M$ and $p \ne \emptyset$. Then there is some $p' \in p$ such that $p' \in Z^- \cap Z^+$ (since $N$ and $M$ are sets of subsets). It follows that $p' > 0$ and $p' < 0$ which is a contradiction. Since $\emptyset$ is a subset of both $Z^-$ and $Z^+$, we have $\emptyset \in N \cap M$. $\proofend$

d)
Im going to invoke some analysis here. Since every nonempty perfect set $P$ in $R^k$ is uncountable, $[0, 1]$ and $[2, 3]$ are uncountable. Hence $A = [0, 1] \cup \mathbb{N}$ and $B = [2, 3] \cup \mathbb{N}$ are uncountable, since $[0,1] \subseteq A$ which would be countable if $A$ were countable (similar for $B$). But $A \cap B = \mathbb{N}$ which is countably infinite. $\proofend$

e)
Since $\mathbb{N}$ and the set $E$ of even natural numbers are countably infinite, $\mathcal{P}(\mathbb{N})$ and $\mathcal{P}(E)$ are uncountably infinite. But $E \subseteq \mathbb{N}$, and so $\mathcal{P}(E) \subseteq \mathcal{P}(\mathbb{N})$. Hence $\mathcal{P}(E) \cap \mathcal{P}(\mathbb{N}) = \mathcal{P}(E)$ which is uncountably infinite. $\proofend$

**Problem 19(a, b, c)**
What is the cardinality of each of the following sets? Prove your answer
a) $\{n \in \mathbb{N} | n \equiv_3 0\}$.
b) $\{n \in \mathbb{N} | n \equiv_3 0\} \cap \{n \in \mathbb{N} | \text{n is prime}\}$.
c) $\{n \in \mathbb{N} | n \equiv_3 0\} \cup \{n \in \mathbb{N} | \text{n is prime}\}$.
**Solution**
a)
Countably infinite. Define $f(n) = 3n$. Suppose $f(x) = f(y)$. Then $3x = 3y$ and so $x=y$ making $f$ 1-1. Now let $m \equiv_3 0$ for some $m \in \mathbb{N}$. Then $3|m$. But this means $3x = m$ for some $x \in \mathbb{N}$. Therefore, $f(x) = 3x = m$ and so $f$ is onto. Thus, $f$ is bijective giving cardinality $\aleph_0$. $\proofend$  

b)
We show that $\{n \in \mathbb{N} | n \equiv_3 0\} \cap \{n \in \mathbb{N} | \text{n is prime}\} = \{3\}$. Clearly, $\{3\} \subseteq \{n \in \mathbb{N} | n \equiv_3 0\} \cap \{n \in \mathbb{N} | \text{n is prime}\}$ since $3 \equiv_3 0$ and $3$ is prime. Now let $p \in \{n \in \mathbb{N} | n \equiv_3 0\} \cap \{n \in \mathbb{N} | \text{n is prime}\}$. Then $p$ is prime and $3|p$. Hence $3x = p$ for some $x \in \mathbb{N}\cup\{0\}$. By definition of prime, its only factors are $p$ and $1$. Since $3 \ne 1$, it must be that $3 = p$. Therefore, $\{n \in \mathbb{N} | n \equiv_3 0\} \cap \{n \in \mathbb{N} | \text{n is prime}\} \subseteq \{3\}$ as desired. Finally, $\{3\}$ is clearly finite as given by the function $f = \{(1, 3)\}$ of cardinality $1$. $\proofend$

c)
Let $A=\{n\in\mathbb{N}:3\mid n\}$ and let $P$ be the set of primes. Since $A\subseteq A\cup P\subseteq\mathbb{N}$, the union is a subset of a countable set and contains the infinite set $A$. Therefore, $A\cup P$ is countably infinite, with cardinality $\aleph_0$. $\proofend$
